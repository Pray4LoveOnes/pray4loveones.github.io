# Privacy notice

Effective: October 5, 2026

The AgentChain GitHub Pages site intentionally has no first-party analytics, advertising trackers, first-party cookies, backend database, wallet connection, transaction signing, account system, membership database, or external form-submission endpoint.

The Technical Evaluation form processes entered information locally in the visitor's browser. “Copy Inquiry” uses browser clipboard functionality, and “Download Inquiry” creates a local text file. AgentChain does not receive the form contents merely because a visitor fills out the form.

The site loads web fonts from Google Fonts. That third-party request, GitHub Pages hosting, and links followed to GitHub or other third-party services are subject to the respective operators' privacy practices and may involve information handled by those services. This notice does not claim that GitHub, Google, or network intermediaries collect no information, and it does not promise absolute anonymity.
