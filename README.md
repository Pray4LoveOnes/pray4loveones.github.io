# AgentChain public website

> **Intelligence may propose. Authority decides. Evidence settles.**

This is the public statement behind the interface: build systems that can act, while keeping authority explicit and outcomes inspectable. The home page, Sovereign City projection, and scientific visualization are static public experiences; none is the AgentChain execution backend.

This repository contains the public AgentChain GitHub Pages website.

Public URL: <https://pray4loveones.github.io>

## Technology

The site is built with static HTML, local CSS, and vanilla JavaScript. It has no backend, database, analytics tracker, cookies, wallet connection, transaction signing, or first-party form endpoint. System font stacks keep page rendering local. The evaluation form prepares text locally and, only after a deliberate click, can open a public GitHub issue with email and private contact fields excluded.

## Deployment

GitHub Pages publishes the `main` branch for `Pray4LoveOnes/pray4loveones.github.io`.

Repository checks run JavaScript syntax validation, internal-link and anchor validation, required-asset checks, JSON parsing, and public truth-boundary assertions before changes are accepted. The Sovereign City page labels its dated capture as a historical local snapshot; the procedural flow page makes clear that it does not run a Navier–Stokes solver.

## Security boundary

No secrets, private keys, seed phrases, credentials, wallet information, private runtime material, or confidential diligence files belong in this repository. GitHub issues are public and must contain only non-confidential inquiry material.
