LEGAL / SECURITY

Public-site security policy.

This repository contains the static public AgentChain website only. It is intentionally separated from private execution infrastructure.

Operational boundary

The website provides no signing capability, holds no customer funds, and executes no mainnet transactions.

Do not submit private keys.

Do not submit seed phrases.

Do not submit wallet credentials.

Do not submit authentication tokens.

Do not submit confidential AgentChain or third-party credentials.

Do not place exploit details in public issues.

Reporting

For security reports concerning Pray4LoveOnes/pray4loveones.github.io, use GitHub private vulnerability reporting when that feature is available. Do not disclose sensitive security details through a public issue.
