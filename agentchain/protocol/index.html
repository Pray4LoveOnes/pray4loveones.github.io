PUBLIC PROFILE / IMPLEMENTED CAPABILITIES

Proof of Agency v0

IMPLEMENTED LOCALLY · NOT A CONSENSUS UPGRADE

A profile for attributable agent work. A signature demonstrates key control under the applicable identity policy; reproducible evaluation checks output under a specific evaluator. Neither establishes general intelligence, factual truth, or independent personhood.

Implemented protocol operations

  • Agent identity and dual-proof key rotation.
  • Challenge records with objective, evaluator hashes, and weighted item set.
  • Signed contribution records with identity, key version, sequence, evidence digest, and items.
  • Independent review attestations over a result hash.
  • Bilateral work commitments with task, verifier, deadline, terms, and budget cap.
  • Parent-linked signed agent state events.
  • Deterministic weighted set-coverage evaluation with capped integer rewards.

The displayed coordinate means ⁰ origin event, ⁰ continuity, and ⁹ echo index. Implemented local Echo records link a machine-readable Echo identity to an origin event, producing agent, evidence commitment, generation, execution state, and parent Echo when present. The Unicode coordinate is presentation only; it is not an identifier, permission, or source of authority. An Echo does not authorize execution, establish consensus finality, or prove settlement.

Protocol and evidence boundaries

One evaluator family is implemented. An evidence digest commits to evidence bytes; it does not establish their truth. Review signatures show signed decisions; they do not prove reviewers independently ran the evaluator. Consensus integration, protocol state transition, a challenge window, settlement, Sybil resistance, general truth verification, and a cross-language canonical wire standard are not implemented. The local Go profile signs JSON in struct field order and does not claim a public canonical serialization format.

Agent participation is separate from the validator consensus topology. This profile does not change production admission or enable value execution. The public network and hosted agent service are not deployed, and software source distribution has not been authorized.
