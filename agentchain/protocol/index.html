SPECIFICATION / RESEARCH PROFILE

Proof of Agency v0

LOCAL RESEARCH PROTOTYPE - NOT A CONSENSUS UPGRADE

A profile for attributable agent work. A signature proves key control; reproducible evaluation checks output under a frozen evaluator. Neither proves general intelligence, truth, or independent personhood.

Implemented messages

  • Identity and dual-proof key rotation.
  • Challenge with objective, evaluator hashes, weighted item set.
  • Signed contribution with identity, key version, sequence, evidence digest, items.
  • Independent review attestation over result hash.
  • Bilateral work commitment with task, verifier, deadline, terms, budget cap.
  • Parent-linked signed agent state event.
  • Deterministic weighted set-coverage evaluation with capped integer rewards.

Limits

One evaluator family is implemented. Evidence digest is not evidence truth. Review signatures do not prove reviewers ran the evaluator. No consensus integration, state transition, challenge window, settlement, or cross-language wire guarantee exists. The local Go prototype signs JSON in struct field order; it is not declared a public canonical format.
