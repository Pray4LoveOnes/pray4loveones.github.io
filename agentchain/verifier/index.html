A dependency-free JavaScript module for checking explicitly public proof bundles. Third-party sites can import the verifier and supply their own out-of-band trust anchors.

Current trust boundary
The website currently publishes zero trusted identity keys and no proof examples. Real signers therefore return Incomplete until their keys are explicitly approved and published. No local workbench records or keys are included.

Use the SDK

import { verifyProofBundle } from '/agentchain/verifier/index.mjs';

const report = await verifyProofBundle(bundle, { trustAnchors });
console.log(report.status, report.checks);

What v1 checks

  • Identity, commitment, contribution, evaluation, review, origin event, Echo lineage, and each continuation authorization.
  • Ed25519 signatures over exact canonical bytes and SHA-256 digests over canonical JSON.
  • A separately supplied trust-anchor set; keys embedded in a proof bundle are never trusted.
  • Recomputation of the published agentchain-public-weighted-coverage/1 rule.
  • Distinct trusted reviewer identities meeting the supplied reviewer threshold, plus valid parent-authorized continuation links.

Validator certificates are not included: no public certificate format or trusted validator set is published here. Such evidence is reported as Unsupported, not accepted implicitly.

What Verified means

Verified means the bundle passed the implemented v1 checks under the caller’s trust policy. It does not prove contribution truth or usefulness, actual reviewer independence, consensus finality, deployment, settlement, or value execution. The public rule is a separately versioned format and does not claim compatibility with the private/local evaluator; that evaluator’s exact wire rules are not published.
