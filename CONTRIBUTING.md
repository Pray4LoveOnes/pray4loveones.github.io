# Contribution policy

This is not an open-source development repository. Unsolicited source-code contributions are not accepted for incorporation into proprietary AgentChain materials unless a separate written contribution or intellectual-property agreement has been approved.

Opening a pull request does not automatically assign intellectual-property rights. No click-through contributor agreement is represented here.

Proposed corrections to public website text may be reviewed, but acceptance is discretionary. Private AgentChain implementation material must never be submitted to this public repository.
